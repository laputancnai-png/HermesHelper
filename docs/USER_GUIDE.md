# HermesHelper 测试指南

## 环境要求

### Linux

- 推荐：Ubuntu 22.04+（或其他发行版，`glib-2.0 >= 2.70`）
- 不支持：Ubuntu 20.04（GLib 版本不足会在 `glib-sys` 构建阶段失败）
- 一键准备环境：

```bash
npm run bootstrap:linux
```

### macOS

- 推荐：macOS 12+
- 需要：Xcode Command Line Tools、Rust、Node.js 20+
- 一键准备环境：

```bash
npm run bootstrap:macos
```

### Windows

- 当前仓库暂未完成正式支持（后端命令实现仍有 Unix 假设）

## 启动应用

```bash
cd /Users/laputancnai/HermesHelper
npm run bootstrap:linux   # Linux 首次执行
npm run bootstrap:macos   # macOS 首次执行
npm run tauri dev
```

首次启动会编译 Rust 后端，约需 2–3 分钟；后续热重载很快。

## 各面板测试项

### 1. Home（总览）

**准备：** 不需要安装 Hermes，可直接测试 UI 状态。

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 未安装状态 | 打开应用，查看 Home 面板 | 版本卡片显示「未安装」，状态为红色 |
| 运行 Doctor | 点击「运行诊断」按钮 | 显示加载动画，然后列出诊断结果（pass/warn/fail） |
| Doctor 徽章 | 诊断完成后 | 顶部徽章变为绿色（全通过）或黄/红（有警告/错误） |
| 跳转安装 | 点击「去安装」快捷入口 | 切换到 Install 面板 |

---

### 2. Install（安装 / 更新）

**前提：** 真实安装需要网络，可只测 UI 流程。

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 平台检测 | 打开 Install 面板 | 显示当前系统平台（macOS arm64 等） |
| 版本检测 | 面板加载 | 若已安装显示当前版本，否则显示「未安装」 |
| 安装按钮 | 点击「安装」 | 进度条出现，实时显示安装日志 |
| 卸载流程 | 已安装时点击「卸载」 | 弹出确认，确认后执行卸载 |

> 若不想真实安装，可跳过此面板，重点测其他面板。

---

### 3. Config（基础配置）

**准备：** 无需 Hermes 已安装。如果 `~/.hermes/config.toml` 不存在，会显示默认值。

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 加载配置 | 打开 Config 面板 | 显示 AI Provider、Model、Language 等字段 |
| 修改并保存 | 改动任意字段，点击「保存」 | Toast 显示「已保存」，`~/.hermes/config.toml` 被写入 |
| API Key 测试 | 填写 API Key，点击「测试连接」 | 显示连接结果（注意：当前为模拟校验，key 长度 > 8 即返回成功） |
| 语言切换 | 切换 Language 下拉框 | UI 语言实时切换（中/英） |

---

### 4. Tools（工具开关）

**准备：** `~/.hermes/cli-config.yaml` 不存在时，所有工具默认全开。

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 初始状态 | 打开 Tools 面板 | 显示 12 个工具的开关列表 |
| 关闭工具 | 将某个工具 toggle 关闭，点击「保存」 | Toast 显示「已保存」，`~/.hermes/cli-config.yaml` 内 cli 列表更新 |
| 重新打开 | 关闭后再次打开 Tools 面板 | 状态与保存一致（已关闭的仍为关） |
| 重置 | 点击「重置默认」 | 恢复全部开启状态 |

---

### 5. Gateway（消息网关）

**准备：** 需要一个 Telegram Bot Token 来测试真实启动；只测 UI 可跳过 Token。

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 状态显示 | 打开 Gateway 面板 | 显示「未运行」状态 |
| 填写配置 | 输入 Bot Token 和允许的用户 ID，点击「保存配置」 | 配置写入 `~/.hermes/config.toml` 的 gateway 节 |
| 启动网关 | 点击「启动」 | 按钮变为「停止」，状态变为「运行中」（需真实 Token） |
| 停止网关 | 点击「停止」 | 状态恢复「未运行」 |

### 6. Migrate（导入 / 导出）

**这是本次新做的面板，重点测试。**

#### 导出测试

**准备：** 先在 Config / Tools 面板保存一些内容，让 `~/.hermes` 有数据。

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 默认全选 | 打开 Migrate 面板 → Export tab | 6 个类别全部勾选，「包含 API Key」未勾选 |
| 导出全部 | 保持默认，点击「导出」，选择保存路径 | Toast 显示「导出成功：/your/path.zip」，zip 文件已生成 |
| API Key 过滤 | 「包含 API Key」保持不勾，导出后解压 | `.env` 中 `*_KEY=` / `*_TOKEN=` 行已被删除 |
| API Key 保留 | 勾选「包含 API Key」后导出，解压查看 | `.env` 内容完整保留 |
| 部分导出 | 只勾选 `config` 和 `memory`，导出 | zip 内只含对应文件 |
| `~/.hermes` 为空 | 删除 `~/.hermes` 后导出 | 导出成功，zip 为空（0 字节内容） |

#### 导入测试

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| Step 1：选文件 | 点击「选择 .zip 文件」，选刚才导出的 zip | 进入 Step 2，显示文件列表 |
| 冲突标注 | 若 `~/.hermes` 存在同名文件 | 对应行显示「(将覆盖)」红色标注，仍默认勾选 |
| 全选 / 取消全选 | 点击顶部「全选」「取消全选」按钮 | 所有勾选框同步变化 |
| 部分导入 | 取消几个文件的勾选，点击「确认导入」 | Step 3 显示「已导入 N 个，跳过 M 个」，N+M = 文件总数 |
| 重新导入 | 点击「重新导入」 | 回到 Step 1，状态清空 |
| 无效 zip | 选择一个非 zip 文件 | Toast 显示「无效的备份文件」 |
